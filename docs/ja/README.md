# Timelapse — このforkで追加した機能

[English](../../README.md#installer-for-this-fork) | **日本語**

このページは、kaki200のforkで追加・変更した部分だけを説明しています。
fork元のREADME本文・既存の開発資料・ライセンス原文は翻訳せず、元の英語のまま残しています。
アプリの画面表示やメニュー名は英語のままです。

## インストール

[リリースページ](https://github.com/kaki200/Timelapse/releases/tag/v2.5.0.10-fork)の
**Timelapse-Kaki-2.5.0.10-win-x64.msi** をダウンロードしてダブルクリックします。
インストール後、デスクトップまたはスタートメニューの **Timelapse (kaki200 fork)** を起動してください。

ExifTool・Perl・LGPL構成のFFmpeg・.NET・必要なVisual C++ランタイムを同梱しているため、
個別のダウンロードやPATH設定は不要です。未署名のため、Windowsやブラウザーの警告が出る場合があります。

## 追加・変更した機能

- チェック項目にキーボードショートカットを設定できます。割り当てたキーはラベルの横に表示され、キー操作でチェックを切り替えられます。
- 動画再生をFlyleafに移行しました。GPUを使った拡大・移動、マウスホイールによる拡大縮小、ドラッグ移動に対応しています。
- キーを押している間の早送り・巻き戻しを維持しています。設定した再生速度が使われます。
- 画像と動画が混在するフォルダーで、ファイルを切り替えてもキーによるシークやフォーカスが正常に扱われるよう調整しています。
- 動画に軽量な動体BBoxを表示できます。Python・CUDA・学習済みモデルのダウンロードは不要です。
- **Window > Data Entry Panel on the right (same window)** で、同じウィンドウの右側にチェック項目を縦一列で配置できます。
- チェック項目を淡い背景色で色分けし、長いラベルは折り返します。配置と右側パネルの幅はウィンドウレイアウトと一緒に保存します。
- 動体BBoxの線を細くしました。主枠は1.5、補助枠は1表示単位です。

## 動体BBoxの使い方と限界

動画の再生操作欄にある **Motion BBox** をONにして動画を再生します。
連続するフレームを比較するため、停止画像だけでは検出を開始できません。

**Options > Video Player Options** から、方式（フレーム差分・MOG2・ハイブリッド）、感度、
枠の余白、下部のタイムスタンプ帯の扱い（自動・手動のピクセル指定・除外なし）を設定できます。
軽い処理から試す場合は、フレーム差分・標準感度を使ってください。

標準では幅640ピクセルに縮小したフレームを解析し、再生とは独立して最大毎秒15回の更新を要求します。
処理待ちを積み上げず、古くなった結果は破棄します。表示だけの機能で、動画や保存済みの認識枠を書き換えません。

これは確認作業の補助であり、動物検出器ではありません。静止した動物の枠が消える、草木の動きに枠が出る、
頭や手足だけが動くと最初は一部分の枠になる、といった限界があります。

## FFmpegと開発用の依存ファイル

ソースのチェックアウトにはFFmpegのネイティブ実行ファイル・DLLを含めていません。
配布用MSIには、専用にビルドしたLGPL構成のFFmpegと対応ソースを同梱しています。

`Installers/PrepareDependencies.ps1` は、固定したソースをダウンロードし、対応する実行ファイルと
共有ライブラリを `.installer-cache/payload/FFmpeg` に用意します。
`Flyleaf.FFmpeg` NuGetパッケージはマネージドバインディングで、ネイティブDLLの配布物ではありません。
同じスクリプトでExifToolとPerlのファイルも用意します。MSIを使う利用者は、別途準備する必要はありません。
